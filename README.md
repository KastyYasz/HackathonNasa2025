# Hackathon NASA 2025 – Identifying Exoplanets

This repository contains our project for the **NASA Space Apps Challenge 2025**, where we tackled the challenge of **Identifying Exoplanets** from light curve data.

## 🚀 Project Overview
The goal of this project was to build a reproducible pipeline capable of processing raw light curve data, applying feature extraction, and leveraging machine learning models to identify potential exoplanet candidates.  
We also created interactive visualizations and a simple frontend to allow users to explore and validate the results.

## 🛠️ Tech Stack
- **Backend / Data Processing**: Python, Pandas, NumPy, SciPy, Scikit-learn  
- **Machine Learning**: Random Forest, Neural Networks (PyTorch)  
- **API**: FastAPI  
- **Frontend**: React + Vite + TailwindCSS  
- **Visualization**: Plotly, Matplotlib  

## 📂 Project Structure
- `backend/` – Data preprocessing, ML pipeline, API  
- `frontend/` – Interactive dashboard for exploration  
- `api/` – Endpoints to serve predictions and processed data  
- `notebooks/` – Experimentation and initial prototyping
